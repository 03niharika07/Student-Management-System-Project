# Student Management System (PHP + MySQL)

A beginner-friendly web-based Student Management System for Software/Application Developer interviews.

## Features
- Admin Login
- Dashboard with total student count
- Add Student
- View Students
- Search Student by name, roll number, phone, or course
- Edit Student
- Delete Student
- Form Validation
- MySQL Database Connectivity

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## How to Run in XAMPP

### 1. Install XAMPP
Start:
- Apache
- MySQL

### 2. Copy Project Folder
Copy the folder `student-management-system` into:

`C:\xampp\htdocs\`

### 3. Create Database
Open browser:

`http://localhost/phpmyadmin`

Create a database:

`student_management`

Then import the file:

`database.sql`

### 4. Open Project
Open browser:

`http://localhost/student-management-system/login.php`
